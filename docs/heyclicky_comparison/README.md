# So sánh với HeyClicky (Windows), 27–28/10/2026

Hồ sơ của một lượt thử HeyClicky bản Windows chính thức trên máy của founder, trước khi viết dòng code nào cho ScreenTutor.

| Đường dẫn | Nội dung |
|---|---|
| `HEYCLICKY_COMPARISON_KIT.md` | Bộ so sánh: các câu yêu cầu, bảng chấm điểm, cách ghi kết quả |
| `test_files/` | File giả dùng để thử (giáo án mẫu `.docx`), cùng checklist và bộ so sánh dạng `.txt` để mở trên Windows |
| `results/` | Checklist và bộ so sánh **đã điền** sau lượt thử. Ảnh chụp `.jpeg` chỉ lưu trên máy (gitignore) vì có tên file cá nhân |

Phân tích kết quả và các nhận định đã được sửa lại nằm trong nhật ký thảo luận của founder (Obsidian), không nằm trong repo này.

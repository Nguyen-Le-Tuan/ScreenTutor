T2: THỬ CẢM BIẾN TRẠNG THÁI WINDOWS (thành phần 1), 29/10/2026
=================================================================
Mục đích: xem cảm biến đọc từ Windows có ĐÚNG không, trên máy giống hệt máy mẹ.
Phép thử này chỉ đọc. Không bấm, không gõ, không sửa gì trên máy.
Kết quả mỗi lần chạy: một đoạn chữ tiếng Việt, đúng thứ sẽ gửi kèm ảnh cho Spark M2.

Luật chấm (ghi trước khi chạy):
  - Đạt: mọi dòng khớp với "Đáp án" bạn ghi trước.
  - Trượt nhẹ: có dòng "Không đọc được ...", tức là cảm biến báo lỗi rõ ràng.
  - TRƯỢT NẶNG: có dòng SAI mà không báo lỗi. Loại này nguy hiểm nhất, vì tutor sẽ tin.
  - Tổng thời gian đọc (dòng "Thời gian đọc ... tổng") nên dưới 500 ms.


A. CHUẨN BỊ (một lần)
---------------------
[ ] A1. Lấy code về Windows. Repo đang để RIÊNG TƯ (private), nên phải đăng nhập GitHub.
        Chọn một cách:
        - Trình duyệt (dễ nhất): đăng nhập github.com, mở
              https://github.com/Nguyen-Le-Tuan/ScreenTutor/tree/mvp
          bấm nút xanh "Code" > "Download ZIP", rồi giải nén.
          (Chưa đăng nhập thì link này báo 404, không phải lỗi code.)
        - Có git: mở PowerShell ở thư mục bạn muốn rồi chạy
              git clone -b mvp https://github.com/Nguyen-Le-Tuan/ScreenTutor.git
          Git sẽ mở cửa sổ đăng nhập GitHub lần đầu.
[ ] A2. Mở PowerShell trong thư mục ScreenTutor (chỗ có thư mục "screentutor").
        Kiểm tra Python:   py --version     (cần 3.10 trở lên)
        Phần cảm biến chỉ dùng thư viện có sẵn của Python, KHÔNG cần pip install.
[ ] A3. Chạy thử một lần:
              py -m screentutor.state
        Lần này cửa sổ trước mặt sẽ là PowerShell. Bình thường, chỉ để chắc lệnh chạy được.
        Nếu báo lỗi đỏ: chụp màn hình lỗi, gửi Claude, dừng ở đây.

Cách chạy cho mỗi kịch bản bên dưới:
        py -m screentutor.state --delay 6 --out t2_results\S-1
  -> trong 6 giây đếm ngược, bấm sang cửa sổ cần thử (đừng bấm lại vào PowerShell).
  -> xong thì quay lại PowerShell đọc kết quả. File lưu ở t2_results\S-1.txt và .json.
  Đổi S-1 thành S-2, S-3... cho từng kịch bản.

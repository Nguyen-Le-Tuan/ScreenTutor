vercel-labs/agent-desktop). Chỉ đọc, không bấm hay gửi gì. Luật U1-U3 ghi sẵn đầu file
tutor_eval\uia_probe.py. Tắt ScreenTutor trước khi dò.
[x] G1.  py -m pip install comtypes
